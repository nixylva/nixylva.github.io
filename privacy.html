Privacy Policy

Last updated: October 9, 2026

Purpose

This application uses rclone to manage and back up files in the owner's Google Drive account. It is intended for personal use only.

Google Drive Access

The application may read, create, modify, and delete Google Drive files using permissions authorized by the account owner.

Data Handling

File operations are performed by rclone on the owner's device. Files are transferred between the device and Google Drive.

OAuth credentials are managed locally by rclone. This website does not collect or store Google Drive files or authentication tokens.

Data Sharing

This application does not sell or share Google Drive data with third parties.

Website Hosting

This website is hosted on GitHub Pages. GitHub's own privacy practices apply to website visitors.

Contact

For questions, contact the application developer using the support email listed on the Google OAuth consent screen.
